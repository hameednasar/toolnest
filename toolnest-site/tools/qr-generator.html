QR Code Generator

Create a QR code from a website link or short text, then download the image.

Your QR code will appear here.

QR generation uses a third-party JavaScript library loaded from a CDN. Do not encode passwords, private information or sensitive data in a QR code.

How to create a QR code

  1. Enter a website URL or a short text message.
  2. Select Generate QR code.
  3. Download the generated PNG image and test it with your phone before sharing.

What can a QR code contain?

A QR code can encode a URL or plain text. The QR code itself does not host a website; it stores the data that a scanner reads.
